이 안내서를 사이트에서 열면 주소와 QR이 자동으로 표시됩니다.

1. 수업 진행 순서 (버튼만 따라 누르면 됩니다)

  1. 교사 컴퓨터: 접속 → 선생님 화면 → 모둠 수 선택 → 🚀 새 게임 → 화면에 방 코드 4자리가 크게 표시됨
  2. 모둠 태블릿: 접속 → 모둠 화면 → 방 코드 + 모둠 이름 + PIN(2자리) 입력 → 입장 (PIN은 태블릿이 꺼졌을 때 재입장용 — 모둠이 기억하게 하세요)
  3. 모든 모둠 입장 확인 후 ▶ 게임 시작
  4. 매 라운드 반복 (버튼 4개): 📰 라운드 시작(뉴스 3장 공개 + 200초 타이머) → 시간이 끝나면 자동 마감 (일찍 끝내려면 ⏹ 매매 마감) → 🔔 시장 공개(진짜 뉴스 공개 + 가격 변동 + 해설) → ➡ 다음 라운드
  5. 10라운드 후 🏁 최종 결과 — 순위·자산 추이 그래프·모둠별 기록. 학생 태블릿에는 성적표가 뜹니다 (학습지에 옮겨 적기)
  6. 수업 끝나면 방 종료 (데이터 삭제 — 학생 성적표는 태블릿에 남음)

실수했을 때: ↩ 되돌리기 버튼으로 직전 단계 하나를 되돌릴 수 있습니다.

2. 게임 규칙 (학생 안내용 1분 요약)

  • 모둠 = 투자회사. 시작 자본 100코인
  • 종목 6개(시작가 10.0): 🚚트럭 🚆철도 🚢선박 ✈️항공 🛸드론 🛢️파이프라인
  • 매 라운드 뉴스 3개 공개 — 진짜(시장을 움직이는) 뉴스는 1개뿐, 나머지 2개는 함정
  • ① 진짜 뉴스 카드 선택 ② 사고팔기 ③ 이유 10자 이상 필수 (수단의 특징으로!) → 매매 확정
  • 정수 주 단위, 빚·공매도·수수료 없음. 관망도 가능(이유는 필수)
  • 최종 자산(현금+주식)이 가장 많은 회사 우승

3. 와이파이가 끊겼을 때 (오프라인 뉴스 코드 모드)

  • 학생 태블릿에 자동으로 🔴 배너 + 코드 입력란이 나타납니다. 게임은 그대로 계속됩니다.
  • 학생이 매매를 확정하면 → 교사가 시장 공개 시점에 화면 상단의 라운드 코드(R-1 ~ R-10)를 구두로 불러줌 → 학생이 입력하면 태블릿에서 가격 변동·해설이 표시됩니다.
  • 모둠 자산은 구두로 보고받아 교사 화면의 [자산 수동 입력]란에 기록하면 순위가 갱신됩니다.
  • 인터넷이 돌아오면 태블릿이 자동으로 다시 동기화됩니다.

5. 자주 생기는 문제

  • "방을 찾을 수 없습니다"가 뜸 → 이전 수업 방이 저장된 것. 🔄 새로 입장하기를 누르고 새 방 코드로 입장.
  • 태블릿이 옛날 게임 화면에 붙어 있음 → 화면 오른쪽 위 나가기 후 다시 입장.
  • 모둠 이름이 이미 있다고 나옴 → 같은 이름의 다른 모둠이 있는 것. PIN이 맞으면 이어하기, 아니면 이름을 바꿔 입장.
  • 여러 학급/여러 선생님 동시 사용 → 문제 없습니다. 방 코드가 다르면 게임이 완전히 분리됩니다. 각자 [새 게임]으로 자기 방을 만들면 끝.
  • 학교망 차단 확인 → 수업 전에 태블릿 1대로 입장 테스트를 꼭 해보세요. (firebasedatabase.app / googleapis.com 도메인이 열려 있어야 실시간 모드 동작. 막혀 있으면 자동으로 오프라인 코드 모드로 수업 가능)

시간 배분 참고: 규칙 4분 → 10라운드(매매 200초 + 공개·해설) → 결과·성적표 → 정리 "수단마다 무너지는 조건이 다르다 — 그래서 물류는 수단을 섞는다". 매매 시간은 게임 파일(game-data.js)의 roundSeconds 값으로 조절할 수 있습니다.
